# aT New York Notice Admin

This Sanity Studio is the editor-facing admin screen for managing website
notices.

## Local Studio

```bash
cd studio
bun install
bun run dev
```

## Deploy Studio

```bash
cd studio
bun run deploy
```

After deployment, add the deployed Studio URL to the Sanity project dashboard
under **Studios > Add studio**.

## Notice Fields

- Title
- Summary
- Date
- Category
- Location
- Button label
- Button link
